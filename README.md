# SmartHire – Online Job Portal System

SmartHire is a modern, full-stack job portal designed to connect candidates with recruiters. Built with the MERN stack and styled with glassmorphism aesthetics.

## 🚀 Features

### For Candidates
- **Modern Dashboard**: Track applications and profile completion.
- **Job Search**: Search by role, location, and skills.
- **One-Click Apply**: Seamless application process.
- **Resume Management**: Upload and manage professional resumes.

### For Recruiters
- **Job Management**: Post, edit, and close job openings.
- **Applicant Tracking**: View resumes and shortlist candidates.
- **Company Profile**: Show-off company culture.

### For Admin
- **User Management**: Monitor and manage all users.
- **Platform Analytics**: Track hiring trends and platform growth.

## 🛠 Tech Stack

- **Frontend**: React.js, Tailwind CSS, Framer Motion, Lucide React.
- **Backend**: Node.js, Express.js.
- **Database**: MongoDB (Mongoose).
- **Security**: JWT Authentication, Bcrypt password hashing.

## 📦 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/kishore-9000/Online-Job-Portal.git
   ```

2. **Backend Setup**:
   ```bash
   cd server
   npm install
   # Create .env file with your MONGO_URI and JWT_SECRET
   npm run dev
   ```

3. **Frontend Setup**:
   ```bash
   cd client
   npm install
   npm run dev
   ```
